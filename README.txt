THE AURELIA STAYS — QR WEBSITE DEPLOYMENT PACKAGE

This package is a WEBSITE, not an HTML download for guests. After hosting it at a public HTTPS URL, the QR code should point to that URL. When a guest scans the QR code, Chrome opens the webpage.

FASTEST PUBLISHING OPTION — NETLIFY
1. Extract this ZIP on your computer.
2. Open https://app.netlify.com/drop in Chrome.
3. Drag the extracted folder (the folder containing index.html) into the drop area.
4. Netlify will publish it and give you a public HTTPS website URL.
5. Open that URL on your phone to test it.
6. Create a QR code that points to the Netlify URL, not to the local HTML file.
7. Scan-test the printed QR code before placing it at the property.

Alternative: publish index.html with GitHub Pages.

FUNCTIONS
- Mobile-friendly page with warm neutral styling.
- Language selector, dice button with full-length draft variations and emojis, copy button.
- Copies the draft and opens The Aurelia Stays on Google Maps.

LIMITS
Google Maps does not let this separate webpage reliably select 5 stars, inject text into the Google review form, or submit a review automatically. The guest must paste/check the text and choose their own rating. Drafts are examples, not verified accounts of a guest's stay; guests should only post content that accurately reflects their experience.
